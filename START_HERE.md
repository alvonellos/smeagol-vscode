## 🔧 Quick Troubleshooting

**Problem:** Code doesn't animate
- Solution: Reload VS Code (`Ctrl+R`)
- Or restart VS Code completely

**Problem:** Colors look wrong
- Solution: Check `docs/PALETTE_SHOWCASE.md`
- Or switch palettes (ADHD/Autism/Stim modes)

**Problem:** Quokka doesn't work
- Solution: Make sure you're pressing `Ctrl+Shift+L` (not `Ctrl+L`)
- And you have code selected

**Problem:** Diagram preview blank
- Solution: Make sure file ends in `.puml` or `.mmd`
- And has valid diagram syntax
