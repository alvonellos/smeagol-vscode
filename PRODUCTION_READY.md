## 🎯 Key Feature: Automatic Complexity Analysis

**This is what makes Smeagol unique!**

### How It Works
```
You open/edit a file
    ↓
Smeagol automatically runs complexity analysis
    ↓
Extracts all functions/methods
    ↓
Calculates cyclomatic complexity (base 1 + decision points)
    ↓
Analyzes branch paths (exponential for nested conditions)
    ↓
Creates diagnostics in Problems panel
    ↓
Color-codes by severity (🟢 green → 🔴 red)
```

### No Commands Needed!
- ✅ Works automatically on file open
- ✅ Works automatically on file save
- ✅ Works automatically on every edit
- ✅ Real-time diagnostics
- ✅ No need to manually trigger

### Complexity Legend
```
🟢 GREEN (1-5)      → Good, no action
🟡 YELLOW (6-10)    → Monitor, maybe refactor
🔴 RED (11-20)      → Refactor soon
🔴🔴 DARK RED (20+) → Critical, refactor now
```
